# 听风实时流

Chrome MV3 侧边栏扩展。它复用已登录听风页面的实时 WebSocket，把预警中的交易标的提取出来，并通过 deBot、GMGN 两个轻量入口打开或复用交易页；也可以使用自己的 Sub2API Key，在侧栏或独立窗口中向 Grok 调查代币叙事。

## 已登录页面桥接

```text
听风页面（同源登录 Cookie）── 官方 wss://wind.jokkimon.club/ws
          ↓ 仅转发收到的协议帧
扩展 Service Worker ── 解析事件 ── 侧边栏 ── 交易网站
```

- 扩展不申请 `cookies` 权限，不读取、不存储、不复制 Cookie。
- MAIN world 脚本只观察听风页面自己创建的官方 `/ws` 连接，不创建第二条连接。
- 隔离环境把原始协议帧转发到扩展后台；后台验证消息必须来自听风顶层页面后才解析。
- 若没有听风标签页，扩展会打开一个非激活页面作为实时流宿主；已有页面会直接复用。
- 桥接有 5 秒心跳和 MV3 Service Worker 状态恢复，页面断线时仍由听风官方逻辑负责重连。
- 当前只展示事件并导航到交易页，不自动下单、不接触钱包签名。

## Grok 叙事调查

1. 在扩展设置的“Grok 叙事调查”中填写 Sub2API 地址、Key 和模型名。地址支持服务根地址、`/v1` 或完整的 `/v1/responses`。
2. 保存时只需授权扩展访问所填写的 Sub2API 域名；Key 保存在 Chrome 扩展的本地可信存储中，不会写入实时流快照。
3. 在有 CA 的预警卡片上点击“问 Grok”。扩展会自动带上链、CA、代币和预警上下文，并启用 X Search 与 Web Search。
4. 在对话顶部点击独立窗口按钮，可以把调查桌单独打开；再次打开时会复用已有窗口。
5. 输入框上方提供“叙事速查”“X 溯源”“风险排查”“热度核验”模板。选择后只会填入输入框，仍可修改或自由输入。
6. 会话会自动保存在 Chrome 本地存储中，侧栏通过历史抽屉查看，独立窗口则常驻显示；最多保留 24 个会话、每个会话 60 条消息。每次请求最多携带最近 10 条消息。

默认模型为 `grok-4.5`，如你的 Sub2API 暴露了其他模型，可直接在设置中替换模型名。

## 本地构建

```powershell
pnpm install
pnpm build
```

打开 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，加载项目中的 `dist` 目录。

## 测试

1. 在听风网站登录，并确认页面“监控列表”数量正常。
2. 刷新扩展。首次升级到页面桥接版时，扩展会刷新一次现有听风页面，以便在页面脚本之前安装桥接。
3. 打开侧边栏，状态应显示“登录态已确认”。
4. Service Worker 控制台应出现 `页面 WebSocket 握手完成 { mode: 'user', watchCount: ... }`。
5. 新事件到达时会先打印 `页面 WS ↓ 收到原始消息`，随后打印“事件已解析并送入侧边栏”，卡片同步出现。

设置页可分别修改 deBot 与 GMGN 的 URL 模板，支持 `{chain}`、`{address}`、`{symbol}` 占位符；外观支持跟随系统、浅色和深色三种模式，页头也可一键切换明暗主题。
